# Gateway Cost & Analytics Implementation Plan

## Problem

The platform has **no concept of gateway buying costs**. Currently:
- Operators have `masking_price`/`non_masking_price` (treated as "cost")
- `ProfitCalculationService` calculates profit as `messages.cost - operator_price * parts`
- But the **real cost** is what the **gateway provider** charges the platform per message, not the operator price
- Messages table has `gateway_id` but no `gateway_cost` field
- No analytics dashboard exists for cost breakdowns

## Solution Overview

1. Create `gateway_operator_rates` table (gateway buying prices per operator)
2. Add `gateway_cost` column to `messages` table (snapshot at send time)
3. Create `GatewayOperatorRate` model
4. Update `ProcessBatchJob` to calculate and store `gateway_cost`
5. Fix `ProfitCalculationService` to use gateway costs
6. Add gateway rates management to Gateway admin resource
7. Build a dedicated Analytics page with charts and breakdowns

```php
Schema::create('gateway_operator_rates', function (Blueprint $table) {
    $table->id();
    $table->foreignId('gateway_id')->constrained()->cascadeOnDelete();
    $table->foreignId('operator_id')->constrained()->cascadeOnDelete();
    $table->decimal('masking_price', 8, 4)->nullable();
    $table->decimal('non_masking_price', 8, 4)->nullable();
    $table->timestamps();

    $table->unique(['gateway_id', 'operator_id']);
    $table->index(['gateway_id', 'operator_id']);
});
```

## Step 3: Gateway Cost Resolver

### Create `GatewayCostResolver` service
**File**: `app/Support/GatewayCostResolver.php`

Similar pattern to `OperatorRateResolver`:
- `forGateway(Gateway $gateway): self` — loads the gateway's rates for all operators
- `resolve(string $e164Phone, bool $isMasking): float` — matches phone to operator, returns gateway cost
- Falls back to `0` if no gateway rate configured (doesn't throw, since gateway cost is informational)

This is used alongside `OperatorRateResolver` during batch processing:
- `OperatorRateResolver` → selling price (what customer pays)
- `GatewayCostResolver` → buying price (what platform pays gateway)

## Step 4: Update Send Pipeline

### Update `ProcessBatchJob`
**File**: `app/Jobs/ProcessBatchJob.php`

In `initialiseBilling()`:
- Load `GatewayCostResolver` for the sender's gateway (alongside existing `OperatorRateResolver`)
- Store as `$this->gatewayCostResolver`

In `priceInsertAndDebit()`:
- After calculating `rate` and `cost` (selling price), also calculate `gateway_cost` per message:
  ```php
  $gatewayCost = $this->gatewayCostResolver?->resolve((string) $row['to'], $this->isMaskingSender) ?? 0;
  $row['gateway_cost'] = round($gatewayCost * (int) $row['parts'], 4);
  ```
- Add `'gateway_cost'` to the row data before `Message::insert()`

## Step 5: Update Profit Calculation Service

### Update `ProfitCalculationService`
**File**: `app/Services/Analytics/ProfitCalculationService.php`

**Change the cost calculation** from using operator prices to using `messages.gateway_cost`:

In `computeForPeriod()`:
- Revenue = `SUM(messages.cost)` (what customers paid) — unchanged
- Cost = `SUM(messages.gateway_cost)` (what platform paid gateways) — **changed from operator price matching**
- Remove the phone-to-operator matching loop for cost calculation (keep it for the operator breakdown)

In `computeOperatorBreakdown()`:
- Keep phone-to-operator matching for grouping
- Use `messages.gateway_cost` for cost instead of operator prices

### Add new method: `getGatewayBreakdown()`
Returns per-gateway: messages, revenue, gateway_cost, profit

### Add new method: `getDailyGatewayCostTrend()`
Returns daily gateway cost trend for charts

## Step 8: Backfill Existing Messages

### Create backfill command
**File**: `app/Console/Commands/BackfillGatewayCosts.php`

- Iterates over existing messages that have `gateway_id` and `gateway_cost = 0`
- Matches phone to operator via `ProfitCalculationService::matchOperator()`
- Looks up `gateway_operator_rates` for that gateway+operator combination
- Updates `gateway_cost = rate * parts`
- Processes in chunks to avoid memory issues
- Run once: `php artisan backfill:gateway-costs`
