# Customer Dashboard Full Upgrade

## Overview

Enhance the existing customer dashboard at `/` with new chart widgets and optimize existing widgets. The customer panel already has 4 widgets — we add 4 new ones and update 1 existing widget.

**Key difference from admin**: Customer widgets use `auth()->user()->{relation}()` which automatically scopes to the logged-in user via `OwnedByUser`.

## Files to Create/Modify

### 1. New Chart Widgets (3)

All in `app/Filament/Customer/Widgets/`, extend `Filament\Widgets\ChartWidget`, `$pollingInterval = '300s'`, `$columnSpan = 1`.

#### `MessageTrendChart.php`
- **Type**: `line`
- **Data**: Messages sent per day for last 30 days
- **Query**: `auth()->user()->messages()->where('sent_at', '>=', now()->subDays(30))->toBase()->selectRaw('DATE(sent_at) as date, COUNT(*) as count')->groupBy('date')->orderBy('date')`
- **Color**: `#10b981` (emerald)

#### `SpendingTrendChart.php`
- **Type**: `bar`
- **Data**: Cost per day for last 30 days
- **Query**: `auth()->user()->messages()->where('sent_at', '>=', now()->subDays(30))->toBase()->selectRaw('DATE(sent_at) as date, SUM(cost) as total')->groupBy('date')->orderBy('date')`
- **Color**: `#0ea5e9` (sky)

#### `CampaignPerformanceChart.php`
- **Type**: `doughnut`
- **Data**: Campaign count by status
- **Query**: `auth()->user()->campaigns()->selectRaw('status, COUNT(*) as count')->groupBy('status')`
- **Colors**: Map from `CampaignStatus` enum colors

### 2. New Stats Widget (1)

#### `ContactStatsWidget.php`
- Extends `StatsOverviewWidget`, `$pollingInterval = '60s'`, `$columns = 3`
- **Metrics**: Total Contacts, Total Groups, Total Templates
- **Query**: `auth()->user()->contacts()->count()`, `auth()->user()->groups()->count()`, `auth()->user()->templates()->count()`
- **Icons**: `heroicon-o-users`, `heroicon-o-folder`, `heroicon-o-document-text`

### 3. Modify Existing Widget (1)

#### `RecentTransactionsWidget.php`
- Change `->limit(10)` to `->limit(5)`

### 4. Dashboard Page Update

#### `app/Filament/Customer/Pages/Dashboard.php`
- Add `getWidgets()` method to control widget ordering
