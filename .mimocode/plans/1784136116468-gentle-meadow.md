# Plan: Add Anbernet SMS Driver

## Summary

Add a new SMS gateway driver for the Anbernet SMS API (`rapi.anbernet.com:9978` / `wapi.anbernet.com:9956`), following the existing Laravel Manager pattern used by `ReveSmsDriver` and `QSmsDriver`.

## Anbernet API Overview

- **Base URLs**: RAPI `https://rapi.anbernet.com:9978/api/v1/` or WAPI `https://wapi.anbernet.com:9956/api/v1/`
- **Auth**: `account` + `password` + `token` (or `api_key` for simpler auth)
- **Send SMS** (`POST /sendsms`): accepts `receivers` array, returns `messageids` array with per-recipient IDs
- **Delivery Check** (`POST /dlrcheck`): status values: `DELIVERED`, `ACCEPTD`, `PENDING`, `NOT_FOUND`, `FAILED`
- **Balance** (`POST /balance`): returns `"Balance Status": "account:balance"`

### 3. `app/Services/Sms/Drivers/AnbernetDriver.php` — New driver class

Implements: `SmsGateway`, `SupportsBulkSms`, `SupportsDeliveryStatus`

**Key methods:**

- **`send(SmsRequest $request): SmsResponse`**
  - POST to `{base_url}/api/v1/sendsms` with JSON body
  - Body: `{ account, password, token, senderid, receivers: [to], msgdata, flashon: 0, transtype: "T" }`
  - Parse response: `messageids[0].messageid` as `gatewayMessageId`

- **`sendBulk(BulkSmsRequest $request): BulkSmsResponse`**
  - POST to `{base_url}/api/v1/sendsms` with receivers array
  - Build `perRecipientIds` from `messageids` response array, keyed by receiver
  - Anbernet returns per-recipient message IDs natively

- **`fetchDeliveryStatus(string $gatewayMessageId): DeliveryStatusResponse`**
  - POST to `{base_url}/api/v1/dlrcheck` with `{ account, password, token, messageid }`
  - Map statuses: `DELIVERED` → `DeliveryOutcome::Delivered`, `FAILED`/`NOT_FOUND` → `DeliveryOutcome::Failed`, `PENDING`/`ACCEPTD` → `DeliveryOutcome::InTransit`

**Error handling:**
  - HTTP failures → `ConnectionException` catch → InTransit (retryable)
  - `{"message": "Wrong credentials"}` with 401 → Failed with error message
  - Response codes 1001-1009 → map to appropriate error messages

### 4. `app/Services/Sms/SmsManager.php` — Add driver factory

```php
protected function createAnbernetDriver(): SmsGateway
{
    if (empty($this->gateway?->credentials['base_url'])) {
        throw new InvalidArgumentException('Anbernet requires credentials: base_url, account, password, token.');
    }

    return new AnbernetDriver(
        credentials: $this->gateway->credentials,
    );
}
```

Add import for `AnbernetDriver`.

## Deployment Compatibility

No changes needed for other deployments:

- The `GatewayDriver` enum adds a new case — existing drivers are unaffected
- `config/sms.php` adds a new driver entry — `SMS_GATEWAY` env default stays `log`
- The Filament GatewayForm dynamically renders fields from `config/sms.php` — Anbernet fields auto-appear when driver is selected
- The `Gateway` model already supports any driver via the enum + encrypted credentials
- Other deployments keep using their existing drivers (ReveSMS, QSMS) — Anbernet is opt-in per gateway record
