# Enable/Disable Individual MNO/IPTSP Carriers

## Summary

Add a multi-select field to the InfoZillion gateway config that lets the admin choose which carriers to check balances for. Options change dynamically based on `api_type` (MNO or IPTSP).

---

## Changes

### 1. `config/sms.php` — Add `enabled_carriers` field

Add after `api_key`:

```php
'enabled_carriers' => [
    'label' => 'Enabled Carriers',
    'type' => 'multi_select',
    'options' => 'dynamic',  // resolved in form builder based on api_type
    'helper' => 'Select which carriers to check balances for.',
    'required' => false,
],
```

### 2. `app/Filament/Admin/Resources/Settings/Gateways/Schemas/GatewayForm.php`

Add `multi_select` type handling in `buildFieldsFromConfig()`:

```php
if ($type === 'multi_select') {
    $field = Select::make("$section.$key")
        ->label(...)
        ->multiple()
        ->options(fn (Get $get) => self::getCarrierOptions($get("{$section}.api_type") ?? 'mno'))
        ->required(false);
    // ...
}
```

Add new static method `getCarrierOptions(string $apiType)`:

```php
private static function getCarrierOptions(string $apiType): array
{
    return match ($apiType) {
        'iptsp' => [
            'ADN' => 'ADN', 'MN' => 'Mirnet', 'BN' => 'Bracnet',
            'AIT' => 'AmberIT', 'RT' => 'RanksITT', 'PRM' => 'Premium',
            'FN' => 'FusionNet', 'BR' => 'Brilliant', 'MTN' => 'Metronet',
            'RCO' => 'RaceOnline',
        ],
        default => [
            'GP' => 'GrameenPhone', 'RB' => 'Robi',
            'TT' => 'Teletalk', 'BL' => 'Banglalink',
        ],
    };
}
```

Key: the `->options()` closure receives `Get $get` and reads `credentials.api_type` to dynamically switch carrier list. Add `->live()` so the options update when api_type changes.

### 3. `app/Services/Sms/Drivers/InfozillionDriver.php`

Filter `$mnoCodes` by `enabled_carriers`:

```php
$enabledCarriers = $this->credentials['enabled_carriers'] ?? [];

if (! empty($enabledCarriers) && is_array($enabledCarriers)) {
    $mnoCodes = array_filter($mnoCodes, fn ($code) => in_array($code, $enabledCarriers));
}
```

If `enabled_carriers` is empty, show all (backward-compatible).

### 4. `database/migrations/2026_07_18_205047_add_infozillion_gateway.php`

No change needed — `enabled_carriers` defaults to empty array (all carriers shown), which is backward-compatible.
